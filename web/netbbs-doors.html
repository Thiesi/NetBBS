Doors & games

Old doors, new ones, one menu.

NetBBS ships with three bundled games: Retro Trivia, Voidrunner and War Dialer. Next to them, a SysOp can add trusted native programs, classic DOS doors through DOSBox-X, doors built for another operating system in a virtual machine per caller, and remote services such as DoorParty and BBSLink. To the caller, they are all just doors.

See them in play Door setup guide
For callers

Pick a door, play, come back.

Native doors, DOS classics and remote services sit in one picker. Both bundled games last between visits: Voidrunner keeps each pilot's career, and War Dialer runs one shared world that every caller plays in.

For SysOps

One profile per door, whatever it runs on.

Every door has a compatibility profile: the adapter that runs it, how its terminal is connected, which drop files it gets, and the limits it runs under. Setup templates fill in the known-good values for the verified games, and setup checks catch mistakes before callers see the door.

How doors run

Limits, adapters and honest boundaries.

Each door is its own process, and the SysOp decides what it may use.

Door runtime

  • Its own subprocess, started without a shell, under enforced CPU, memory, time and process limits.
  • Resource limits, not a sandbox. A native door can read what the service account can, so install only doors you trust.

Classic DOS doors

  • LORD, TradeWars 2002 and Global War through an operator-installed DOSBox-X, over an emulated serial/FOSSIL link.
  • Classic drop files: DOOR.SYS, DORINFO1.DEF, CHAIN.TXT and DOOR32.SYS. CP437 output is converted for callers' UTF-8 terminals.

Native, remote and VM

  • Native and remote: stdio, a controlling terminal, a private DOOR32 socket, or an allowlisted remote door service such as DoorParty or BBSLink.
  • Doors from other platforms run in their own qemu guest per caller, with no network and only two shared directories. POSIX hosts only.

Doors that talk back

  • An opt-in, per-door hook lets a game post to chosen message boards and speak in chosen chat channels, under hourly ceilings the SysOp sets.
  • Verified, and says so. The door setup guide lists which games and adapters have been checked on NetBSD and Debian, and which have not.

Run a node, open the door menu.

The bundled games work out of the box. The door setup guide covers everything else.
