Run a BBS you actually own

A text-based home for your community: message boards, live chat, personal mail, file sharing, and door games on a server you run and moderate. Callers connect through a browser, SSH, or Telnet. Run independently, join other nodes through NetBBS Link, or connect chat channels to the MRC network.

Getting in

A browser or your favorite terminal.

Offer the connection methods your community uses. Browser callers need no additional software; terminal callers use an SSH or Telnet client.

Telnet

The classic path — any terminal, any telnet client, on the port you choose.

SSH

Key or password auth over an encrypted channel — the transport most operators reach for by default.

Web

A real terminal in the browser via xterm.js — send a link, they're in. No app, no extension.

Bundled games

Give callers a reason to return.

Build a space-trading career in Voidrunner, lead a crew through War Dialer's fictional BBS network, or play a quick round of Retro Trivia. All three ship with NetBBS and can be registered from the SysOp's game gallery.

Voidrunner — your space-trading career

A persistent deep-space trading career: routes, contracts, cargo, faction standing, and a ship that takes damage and has to be repaired. Every screen now reads as an instrument panel.

  • Gauges on one scale. Hull, fuel and hold share a twenty-cell bar beside the ship's own silhouette, so one glance says what is wrong.
  • The market is a table. Seven columns where there were seven sentences, and a sparkline putting the quote in front of you against that commodity's price in all five economy types.
  • Alerts carry the key that answers them. A critical hull is red with [Y] repair; contraband aboard is amber with [D] jettison.
  • Motion you can switch off. Screens reveal as you arrive at them and hull bars drain when a shot lands — and a new Full palette, no motion preset turns every bit of it off.

War Dialer — a phosphor terminal

Run a crew across a ten-exchange network: case a target, pick an approach, take it before a rival does, and keep your Heat under the level that gets you busted.

  • The ring is the map. Ten exchanges drawn with their connections and coloured by who holds them, with consistent colours across the map and reports.
  • Every gauge means something. Cash, Heat, crew, turns and holdings across the top, over a rank ladder with your own rung lit.
  • A number is an exchange, not a row. Press a digit for its own card: owner, defence, your odds as a bar, the capture price and its neighbour discount.
  • Keep your progress. Shared-world actions are saved as you play, and any key skips the result animation.

The bundled games need no separate runtime. For classic DOS doors, install your game and a compatible DOSBox-X build, plus a FOSSIL driver where the game requires one. The door setup guide has the build patches, the tested matrix and the checks to run.

NetBBS Link

Independent communities, connected.

Independent nodes find each other and share message boards, chat channels, mail, and file catalogues. You choose what your node carries and who it trusts. NetBBS Link is a separate setup choice; project-operated reliable nodes help with discovery and relay. Federation remains private and experimental while real-world validation continues. A standalone node is a complete BBS.

  • Signed node identity. Every peer is a cryptographic keypair, not a hostname you have to trust blindly.
  • Trust that's earned, not assumed. Reputation and vouching decide how much a linked node's content is worth to you — and every decision is visible and overridable by a SysOp.
  • Real-time, across nodes. Live chat channels stay live over NetBBS Link, not just asynchronous mail and post sync.
  • Reachable behind NAT. Automatic relay selection means even an outgoing-only node can still be found.

Get started

Start with a local look around.

With Python 3.11+ installed, download a wheel from GitHub Releases. In a fresh directory, replace VERSION below with its filename. The SysOp handbook covers a permanent installation.

shell 
# install the downloaded release in a local environment
python3 -m venv .venv && . .venv/bin/activate
python -m pip install "./netbbs-VERSION-py3-none-any.whl[ssh,web]"

# create yourself as SysOp (prompts for username/password), then start the node
python -m netbbs.admin --db netbbs.db
python -m netbbs --db netbbs.db --ssh-host 127.0.0.1 --disable-link

For this local trial, decline network participation and managed DNS during setup. From another terminal, run ssh -p 2222 yourname@localhost using the account you created. On NetBSD, install the SSH build prerequisites from the handbook first. For source development, see the developer handbook.
